# External Dependencies

## PortAudio
- **Purpose:** Cross-platform, open-source C library for real-time audio I/O.
- **Type:** Pre-compiled static/dynamic library.

## nlohmann/json
- **Purpose:** Parse JSON configuration files.
- **Type:** Header-only modern C++ library.
- **Location:** `third_party/json/`

## GLFW
- **Purpose:** Cross-platform API for creating hardware-accelerated windows and receiving input.
- **Type:** Source library.
- **Location:** `third_party/glfw/`

## Dear ImGui
- **Purpose:** Bloat-free graphical user interface for C++ with minimal state. We use the `docking` branch for professional IDE-style workspaces.
- **Type:** Source library.
- **Location:** `third_party/imgui/`

## ImNodes
- **Purpose:** A small, dependency-free node editor extension for Dear ImGui.
- **Type:** Source library.
- **Location:** `third_party/imnodes/`
