# Real-Time Audio Processing Engine

A professional-grade real-time audio processing engine built in Modern C++.

## Goals

This project is being developed from scratch to understand the complete architecture of a real-time audio engine.

Features planned:

- Real-time audio streaming
- Lock-free Ring Buffer
- Multi-threaded processing
- Modular DSP architecture
- Gain Effect
- Low-Pass Filter
- Equalizer
- Reverb
- Runtime parameter control
- Low-latency audio pipeline
